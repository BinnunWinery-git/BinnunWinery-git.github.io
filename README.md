# לומדים את בן נון

אפליקציית לימוד לצוות יקב בן נון: כרטיסיות לכל בקבוק, הסבר על זני הענבים, היסטוריית היקב, וחידונים.

האתר החי: https://binnunwinery-git.github.io/

## עדכון
- כל התוכן נמצא ב-`index.html` (רשימת היינות במשתנה `WINES`, הענבים ב-`GRAPES`).
- אחרי כל שינוי ב-`index.html` מעלים את המספר ב-`VERSION` בקובץ `sw.js`, כדי שטלפונים שהתקינו את האפליקציה יקבלו את העדכון.
